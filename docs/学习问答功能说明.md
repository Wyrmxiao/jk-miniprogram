# 学习问答功能说明

> 需求：在学习模块里新建功能，学生提出自己的问题，老师和同学可以查看并解决。
> 完成日期：2026-11-04

---

## 一、功能是什么

一个挂在学习模块下的**问答互助区**，不是留言板：问题有状态、回答可被采纳、解决后可重开。

| 角色 | 能做什么 |
|---|---|
| 学生（已实名） | 提问、查看全部问题、回答他人问题、采纳自己问题下的答案、删除自己的问题/回答 |
| 教师 / 管理员 | 以上全部 + 直接标记任意问题为已解决（线下已讲清的场景）、重新打开、删除不当问题与回答 |
| 未认证用户 | 学习页与问答页显示「去认证」引导，不能读写 |

**解决的两条路径**：
1. **采纳答案**（提问者本人或教师）→ 问题自动变为「已解决」，采纳答案高亮置顶
2. **教师直接标记已解决**（线下答疑、面谈后）→ 不产生采纳标记

已解决的问题**仍允许补充回答**，不硬切断讨论；重新打开会清掉采纳标记并恢复可采纳。

## 二、入口与页面

| 位置 | 说明 |
|---|---|
| `pages/learn/learn` | 新增「学习问答」入口卡片，显示当前待解决数、我的提问数 |
| `pages/learn/qa` | 问答列表：概览数字、搜索、状态筛选、分类筛选、问题卡片、右下角提问按钮 |
| `pages/learn/qaDetail` | 问题详情：完整描述、回答列表、采纳、底部回答栏 |

列表页筛选维度：

- **状态**：全部 / 待解决 / 已解决 / 我的提问 / 我回答过
- **分类**：算法题 / 课程学习 / 项目开发 / 竞赛备赛 / 其他
- **关键词**：标题、正文、提问人（模糊匹配，可与分类叠加）
- **排序**：按 `lastActivityAt` 倒序，有新回答的问题会浮上来
- 下拉刷新 + 上拉分页（每页 20 条）

提问表单含「相关题目（选填）」字段，学生可写「两数之和 / cf:4:A」，与刚完成的 820 题题库呼应。

## 三、前后端链路

严格按项目约定：页面 → `services` → `utils/request` → 云函数 → 数据库，前端不碰数据库。

```
pages/learn/{qa,qaDetail,learn}
   ↓ miniprogram/services/index.js 的 qa 组
utils/request.js  →  DOMAIN.LEARN（learn 云函数）
   ↓ cloudfunctions/learn/router.js
cloudfunctions/learn/handlers/qa.js
   ↓ qa_questions / qa_answers 集合
```

### 接口清单（`learn` 域，9 个）

| action | 作用 | 权限 |
|---|---|---|
| `qaList` | 列表（scope/category/keyword/page/size） | 登录 |
| `qaStats` | 待解决 / 已解决 / 我的提问 计数 | 登录 |
| `qaDetail` | 问题 + 回答列表，浏览数 +1 | 登录 |
| `qaAsk` | 提问 | 已实名 |
| `qaAnswer` | 回答 | 已实名 |
| `qaAccept` | 采纳答案 | 提问者本人或教师 |
| `qaSetStatus` | 标记解决 / 重新打开 | 提问者本人或教师 |
| `qaRemoveQuestion` | 软删除问题（级联下架回答） | 作者或教师 |
| `qaRemoveAnswer` | 软删除回答 | 作者 / 提问者 / 教师 |

### 集合（用 `ensure()` 自愈，无需手工建表）

**`qa_questions`**
`openid / authorName / authorRole / title / content / category / tags[] / problemId / problemTitle / status / answerCount / viewCount / acceptedAnswerId / solvedBy / lastActivityAt / createdAt / updatedAt`

**`qa_answers`**
`questionId / openid / authorName / authorRole / content / accepted / status / createdAt / updatedAt`

### 设计取舍

- **回答独立成表**：避免单文档膨胀，也才能反查「我回答过的问题」
- **计数冗余在问题里**：列表页零额外查询；删除回答时反向扣减
- **软删除**：`status='removed'`，列表用 `_.neq('removed')` 过滤；不做物理删除，避免误删无法追溯
- **权限字段后端算好**：`canManage / canAccept / canDelete / isMine / isTeacher` 直接随数据返回，WXML 不做方法调用（项目硬约定）
- **列表不返回正文全文**：只回 90 字摘要，减少传输

## 四、复用既有约定

- 莫兰迪色板，全部走 `variables.wxss` token，无硬编码 iOS 亮色
- 复用 `mixins.wxss` 的 `hero / seg / badge / tag / mask / sheet / field / opts / opt / btn / pressable`
- 弹层：遮罩 `bindtap` 关闭 + `sheet catchtap="noop"`
- 键盘遮挡：`cursor-spacing`（input 120 / textarea 240）+ `bindkeyboardheightchange` 收起固定栏与 FAB
- WXML 条件链里不夹 HTML 注释作为兄弟节点
- 分段控件横向滚动时覆盖 `.seg` 的等宽/底色属性，避免灰条
