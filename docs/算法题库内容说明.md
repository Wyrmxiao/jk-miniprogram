## 三层内容，严格区分

不拿模板冒充逐题解析，这是本次最重要的设计决定。

**1. 完整题面（`statementHtml`）**
- LC：leetcode.cn GraphQL 的 `question.translatedContent`，中文题面
- CF：`codeforces.com/problemset/problem/...` 的 `problem-statement` 块
- 都清洗成小程序 `rich-text` 可渲染的 HTML：剥 class/style/script、代码块转成带行内样式的 div、LaTeX 命令转可读符号（`\le`→`≤`、`$$` 分隔符去掉）
- 附带元数据：LC 难度、CF 时限与内存

**2. 解题过程（`solution`）**

| 类型 | 题数 | 内容 |
|---|---|---|
| `editorial` 逐题精讲 | **20** | 一句话点破考点 → 分步推导（写「为什么这样想」）→ C++17 完整代码 → 逐段代码解析 → 复杂度 → 本题最容易 WA 的一处 |
| `framework` 通用框架 | 800 | 按本题主知识点给出通用解题步骤，**页面顶部明确写「不是本题的逐题题解」** |

20 道精讲覆盖全部 14 个知识点：`simulation` `sort` `binary` `prefix` `twopointer` `greedy` `recursion` `dp` `graph` `tree` `ds` `string` `search` `math`。

**3. 涉及的知识点（`knowledge`）**
14 个知识点，每个含：一句话定义 / 识别信号（题面里能看见的措辞）/ 解题步骤 / C++ 参考代码 / 会真的 WA 的易错点 / 复杂度 / 相邻知识点。
精讲题额外带 `why`：本题为什么用到这个知识点。

## 页面交互

三个分段标签：**完整题面 / 解题过程 / 知识点**。

**背题模式**：切到「解题过程」或「知识点」时，内容默认收起，显示一条提示「先自己想一遍，卡住了再点开看」。点开才显示解析。这是把 Errichto 那条「读到新东西就停」的思路落成了交互。

知识点卡片默认折叠，点标题展开看识别信号、参考代码、易错点。

内容**按需加载**：列表页和详情页首屏不带题面，进页才请求 `algoProblemContent`（支持 `sections` 只取部分）。

## 体积优化

初版把 14 个知识点的完整讲解重复写进 820 道题，内容包 **6022KB**。改成知识点单独一份、题里只存 `key + why` 引用后，降到 **3224KB + 20KB = 3244KB**，砍掉约 46%。

## 已知的坑（记录备查）

- **LC GraphQL 字段是 `question` 不是 `questionData`**；用错会报 `Cannot query field`。
- **Codeforces 必须用带浏览器 UA 的 curl**：Node `https` 模块的 TLS 指纹会被 Cloudflare 判 403，curl 带 UA 稳定 200。这也是抓取器用 `execFile('curl')` 而非 https 的原因。
- **CF 的 KaTeX 分隔符是混排的**（`$$n$ ... $k$$`），只处理单 `$` 会残留 398 题的美元符号。
- **题库 pid 格式**：CF 是 `4A`，但 problem.id 是 `cf:4:A`；LC 的 id 是 `lc:<slug>` 而非题号。写精讲时按这个格式。
- 云函数本地没有 `node_modules`，校验用 `node --check`；接口测试用 `Module._load` 拦截 `wx-server-sdk` 做 mock。

## 还没做的（诚实边界）

1. **800 题只有通用框架，不是逐题题解**。页面已明确标注，不会误导学生。要补精讲，在 `tools/algo_editorials.js` 里按 `problem.id` 加一条即可，重跑 `node tools/build_algo_content.js` 会自动从 framework 升级成 editorial。
2. **9 道会员题无题面**。力扣官方不开放，不是抓取失败。页面降级为「题面补充中」并保留知识点与去官方做题按钮。
3. **留言与收藏**：集合已在 `algo.js` 头部预留（`algo_problem_comments` / `algo_favorites`），接口与页面尚未实现。这是上一轮需求里挂起的部分。
4. **需要部署**：`learn` 云函数要重新部署才会带上两个新 JSON。用 `cli.bat cloud functions deploy --project <路径> --env cloud1-d5gr2v7tz34fafa7c --names learn --remote-npm-install`。注意当前 AppID 与婚礼小程序共用，上传体验版会覆盖对方代码。
