## 交互重构
| 原来 | 现在 | 收益 |
|---|---|---|
| 每个动作弹窗 | **行内展开**（grid-template-rows 0fr→1fr） | 回复反馈后视线不动，直接处理下一条 |
| 看板八张等大指标卡 | 1 个焦点块 + 2 组图表 | 一眼看到「今天要干什么」 |
| 状态四色并用 | 只在需决策时上色，完成态转中性 | 红不再既表示待处理又表示危险 |
| 成长档案独立弹窗 | 右侧抽屉（保留上下文） | 关掉还在原列表位置 |
| 14 个独立页面 | 单页路由，视图切换 340ms | 无刷新、无白屏 |

## 代码简化
- **14 个 HTML 页面 → 1 个文件**：805 行，含全部视图、抽屉、动效
- **数据驱动渲染**：`D` 数据对象 + `VIEW` 表 + 4 个共用渲染器（`table/bars/donut/line`）
- **单一事件委托**：全站 1 个 click 监听，靠 `data-*` 分派，不写 20 个 addEventListener
- **零依赖**：无 Vue、无 ECharts、无 Tailwind。图表是手写 SVG（`pathLength=1` 让描线动画与数据长度无关）
- 落地换成 ECharts 5 时，只需替换 `lineChart/donut` 两个函数，其余不动

## 动效四层（守技术确认单时长区间）
| 层 | 参数 | 位置 |
|---|---|---|
| 视图切换 | translateY(10px)+opacity 340ms | `@keyframes viewin` |
| 卡片入场 | stagger 65ms × 500ms | `--i` 变量 |
| 数字滚动 | 700ms 三次缓出 | `afterMount()` |
| 控件反馈 | hover 160ms / press scale(.97) | `.btn:active` |
| 附加 | 折线描线 1.1s / 条形宽度 900ms / 环形弧长 900ms | 图表专属 |
全部 `prefers-reduced-motion` 一键降级。
