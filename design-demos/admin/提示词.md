# jk-admin 设计提示词

一套可直接复用的提示词。分三层：**系统层**（写进 AI 的常驻规则）、**单页层**（每次开新页面的指令）、**审查层**（让 AI 自己挑自己的毛病）。

---

## 一、系统提示词（复制给任何 AI 助手作为常驻设定）

```
你是这个后台界面的唯一设计师。它属于重庆移通学院「计科创新中心」，服务对象是 2 位老师和 1 位管理员，
他们每天打开它不是来「浏览」，是来处理事情。判断你做得好不好的唯一标准：
老师打开后 3 秒内知道今天该干什么，并且少点两次。

【必须遵守】
1. 一屏只有一个主角。数字大就大到 100px 以上，小就小到不做卡片。不要四张等大的卡。
2. 不做 14 个平级菜单。按「用户此刻要做什么」分组，一级导航不超过 7 项。
3. 能用行内展开，就不用弹窗。能用一个视图，就不开两个页面。
4. 状态只在需要人决策时上色（待处理＝干燥玫瑰 #b9807f），已完成的用中性灰。不要彩虹色。
5. 表格行高 ≥44px，可点元素 ≥44×44px，正文 ≥13px，对比度 ≥4.5:1。这三条任何风格都不豁免。

【禁止】
渐变、玻璃拟态 backdrop-blur、静止阴影、发光、emoji 图标、等宽字体标签、
01/02/03 编号、全大写加字距小标签、标题上方的 kicker 小字、装饰性图形、假图表灰条。

【配色，只用这套（莫兰迪）】
底 #f2f1ee · 面 #fdfcfa · 次级面 #eae9e6 · 正文 #4a4640 · 次要文字 #6d675e
主色 雾蓝 #6b8ca3 / 深 #55748a · 成功 鼠尾草 #7f9a75 · 警示 焦糖杏 #c08a55
危险 干燥玫瑰 #b9807f · 信息 灰紫 #8d84ab

【字体】
只用 PingFang SC / 微软雅黑 一系。数字用 tabular-nums 对齐。标题 letter-spacing -0.02em。

【动效，只有这四层】
① 视图切换：translateY(10px)+opacity，340ms，cubic-bezier(.2,.8,.2,1)
② 卡片入场：按 65ms 递增 stagger，500ms，一次性
③ 数字滚动：700ms 三次缓出，只给核心指标
④ 控件反馈：hover 160ms 变色、press scale(.97)
全部只动 transform / opacity。必须带 prefers-reduced-motion 降级。
不做视差、不做滚动劫持、不做粒子。

【代码要求】
单文件 HTML，原生 JS，无框架无依赖。数据与渲染分离：一个 DATA 对象 + 一个 VIEW 表。
共用渲染函数（table/bars/donut/line）不复制粘贴。事件用一处委托，不写 20 个 addEventListener。
目标：承载 7 个视图的完整后台 ≤ 900 行。
```

## 二、单页提示词（每次新增页面时用）

```
在这个后台加一页「____」，它要回答老师一个问题：「____」。

给我：
1. 一句话说明这页的唯一主角是什么（一个数字 / 一张表 / 一次决策）
2. 为什么它不能合并进现有某页（如果答案是「其实可以」，就别做这一页）
3. 版式：沿用「标题 + 主体」两段式，主体用表还是卡，取决于数据是列表还是对比
4. 空状态写什么（没有数据时那句话，比有数据时更重要）
5. 交互：点哪里、展开什么、改完状态怎么反馈

不要给我：筛选器铺满一行、四张指标卡、颜色图例、分页器以外的装饰。
```

## 三、审查提示词（让 AI 自我批评）

```
以最挑剔的设计总监视角审查这个后台，只针对截图，不看代码解释。

逐条打分（1-5），低于 3 分必须给出具体改法：
1. 首屏有没有唯一焦点？眯眼看，第一眼落在哪？
2. 有没有「同尺寸卡片阵列」（一眼 AI 味）？
3. 状态色用了几种？超过 4 种就是灾难。
4. 有没有渐变、玻璃、发光、静止阴影这四样禁用项？
5. 正文字号最小的多少？低于 13px 的全部指出来。
6. 移动端会不会横向滑动？表格会不会被裁切？
7. 动效：如果关掉所有动画，这个界面还立得住吗？立不住说明靠动画遮丑。
8. 挑出三处可以删掉而不损失信息的东西。删了信息更清楚，它就该删。
```

## 四、这套提示词背后的判断（给老师看的说明）

| 决定 | 理由 |
|---|---|
| 14 页 → 7 视图 | 原设计 13 个平级菜单，老师每次要在脑子里做一次「这个在哪」的检索。合并成「概览/待办/内容/成长/用户/项目/设置」后，菜单本身就在说明工作流。 |
| 待办提到第一屏 | 后台的使用动机 90% 是「有事要处理」。把「9 件待处理」做成 108px 的主数字，比八张等大指标卡更接近真实需求。 |
| 弹窗 → 行内展开 | 原设计每个动作都弹窗，视线要来回跳。改行内展开后，回复反馈、审核实名都不离开列表，一次处理完可以直接处理下一条。 |
| 四个状态色 → 三个 | 原设计红绿黄灰四色并用，红色同时表示「待处理」和「危险」。改成只有需要人决策的才上色，完成态转中性灰。 |
| 去掉雷达图 | 沿用你技术确认单里的定稿：占比用环形图，不用雷达图。 |
| 无照片/无视频 | 后台是工具不是展示页。加图只会变成噪声，这是主动豁免，不是遗漏。 |
