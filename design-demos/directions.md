# jk-admin 管理后台 · 重新设计 · 方向卡

> 题材：重庆移通学院计科创新中心 · 竞赛管理后台（14 页）。学生 v1 = 经典 Element Plus 蓝白后台模板（深蓝侧栏 #0F2B47 / 主色 #2563EB / 状态色红绿黄），规整但"通用后台"感偏重。本重设计**保留全部功能与真实数据**，只换视觉语言、栅格结构、动效节奏。
>
> 硬约束（来自技术确认单）：动画轻量三件套（淡入 150ms / 弹窗缩放 120ms / hover 过渡 100ms），AI 仅静态占位，不接真模型，图表全 ECharts。

## 六个候选 → 挑三

1. **最佳设计师 · 原研哉 / Swiss 编辑感**（已选）
   借：极密留白、强栅格、字阶担纲、1–2 色克制；主色墨黑 + 纸白 + 单一朱红/深蓝点睛；无圆角、发丝分隔线、大号数字。
   主角：数据本身（大号统计数字 + 手绘 SVG 图表）。骨架：细左栏 + 12 栏内容栅格。
   form：运营后台 = 安静扫读，留白让老师聚焦数字。

2. **现实参照 · Linear / Vercel 深色工具**（已选）
   借：近黑画布、玻璃面板、柔和辉光、等宽数字、微交互抬升。主色雾蓝 #6b8ca3（与小程序莫兰迪体系同源）做 acccent。
   主角：玻璃卡片里的图表，hover 微光。骨架：深色侧栏 + 玻璃内容区。
   form：算法竞赛圈层 = 极客/终端气质，深色更聚焦数据。

3. **品牌同源 · 莫兰迪暖调卡片**（已选）
   借：燕麦白底 #f4f1ec、暖白卡片 #fffdf9、雾蓝 primary、鼠尾草绿/焦糖杏/干燥玫瑰状态色——与同项目小程序**同一套设计系统**。圆角、暖阴影、rise-in 入场。
   主角：柔和色块状态芯片。骨架：浅色侧栏 + 呼吸感卡片流。
   form：后台与小程序一体感，温暖不冷峻，降低老师使用门槛。

4. 备选 · 粗野主义大字号（过头，弃）：整页巨字模块网格，去掉信息更糊，弃。
5. 备选 · 报纸头版隐喻（过头，弃）：把后台做成报纸，弃。
6. 备选 · 终端命令行外壳（过头，弃）：拟物终端，弃。

> 三版温度/骨架各异：A 冷·编辑平面；B 暗·玻璃工具；C 暖·圆角卡片。三套**不共用外观家族**，满足三方向门。
